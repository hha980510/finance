# 현성·세연 가계부

월 수입 · 예산 · 지출을 기록하고 분석하는 가계부 웹앱 (Next.js 16 + TypeScript + Tailwind + Recharts).

## 기능

| 탭 | 내용 |
|---|---|
| 대시보드 | 핵심 지표(수입·소비·월말 예상·저축·순현금흐름·하루 사용 가능액), 자동 진단, 변동지출 소진 곡선, 카테고리 사용률, 수입 배분 |
| 거래내역 | 추가/수정/삭제, **고정지출·수입 한 번에 자동 입력**, 검색·필터(카테고리/결제자/구분/기간)·정렬, CSV 내보내기 |
| 예산 대비 실적 | 카테고리·그룹별 예산/실적/차이/사용률(오늘 페이스 표시)/월말 예상/상태, 차이 차트 |
| 추세 | 월별 수입·소비·저축 + 3개월 이동평균, 저축률 추이, 필수/선택/헌금 구성, 카테고리×월 히트맵, 전월 대비 |
| 재무 진단 | 스코어카드(주거비·고정비·실질저축률·헌금 비율·비상금 개월수·손익분기 수입), 수입 워터폴, 50/30/20 비교, 결제자별 지출, 지출처 Top, 이상 거래 탐지(Z-score) |
| 시뮬레이터 | 수입·항목별 예산을 슬라이더로 바꿔 결과 비교, **적자 해소안 / 저축률 달성안 자동 생성**, 예산에 적용 |
| 예산 계획 | 수입원·예산 항목 편집 (고정/변동/저축, 필수/선택/헌금/저축 분류, 납부일). 예산을 바꿔도 지난 달 분석은 당시 예산으로 유지 |
| 목표 | 저축 목표별 필요 월 저축액·달성 가능 여부, 비상금 잔액 |
| 데이터 | 기존 엑셀 가계부(.xlsx 월별 시트) 가져오기, 분석 리포트 엑셀(수식 포함)·CSV·JSON 백업, 클라우드 동기화, 설정 |

## 로컬 실행

```bash
npm install
npm run dev   # http://localhost:3000
```

## Vercel 배포

1. 이 폴더를 GitHub에 push
2. vercel.com → **Add New → Project** → 저장소 선택 → Deploy (설정 변경 불필요)

기본은 데이터가 **각 브라우저에만** 저장됩니다(백업은 ‘데이터’ 탭).

### (선택) 두 사람이 폰·PC에서 같은 데이터 보기

1. Vercel 프로젝트 → **Storage → Marketplace → Upstash (Redis)** 생성 후 프로젝트에 연결
   → `KV_REST_API_URL`, `KV_REST_API_TOKEN` 환경변수가 자동으로 추가됩니다.
2. **Settings → Environment Variables** 에 `APP_PASSCODE` (원하는 비밀번호) 추가 → Redeploy
3. 앱의 ‘데이터’ 탭에서 같은 비밀번호 입력 → 연결

## 구조

```
app/page.tsx            탭 셸
app/api/data/route.ts   클라우드 동기화 API (Upstash REST)
lib/analytics.ts        분석 엔진 (월 통계, 계획 분석, 추세, 소진 곡선, 이상 탐지, 연말 예측, 목표)
lib/insights.ts         자동 진단 규칙
lib/defaults.ts         기본 예산 · 엑셀 종류 → 카테고리 매핑
lib/io.ts               엑셀 가져오기/리포트, CSV
lib/store.ts            저장소 (localStorage + 선택적 클라우드)
components/*            각 탭 화면
```
